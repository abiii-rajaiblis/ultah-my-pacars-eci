# Desi Ayulia — 24th Birthday ♡

Gabungan **Cute UI** dan **V2 Coquette Scrapbook**.

### Yang dipertahankan dari Cute UI
- Opening surprise
- Gift box interaktif
- 24 candles
- Message typing
- 6 memory photos asli
- Birthday video
- Music player + seek + volume
- 4 letters
- 24 little things
- Secret garden
- Final birthday page

### Yang diambil dari V2
- Typography scrapbook/serif + handwritten
- Layout yang lebih elegan dan tidak terlalu ramai
- Page record/vinyl di pojok kiri
- Foto Page 3 dapat di-swipe/arrow/dots
- Pink coquette sebagai warna utama
- 6 frame Page 4

## GitHub Pages
Upload semua isi folder ini ke repository GitHub, lalu Settings → Pages → Deploy from branch → main/root.

File media sudah ikut disertakan di `assets/photos`, `assets/video`, dan `assets/music`.
